# 句刻网站品牌基线

## 品牌资产

- App 图标：`assets/app-icon.png`
- 中文 App Store 截图：`assets/store/zh-Hans/`
- 英文 App Store 截图：`assets/store/en-US/`
- 分享卡片示例：`assets/app-share.png`

App 图标和 App Store 截图均来自 `MicroSpotlight/daily-quote` 主仓的正式设计与发布产物，不使用第三方替代图标或仿制 UI。

## 视觉系统

- 纸色：`#F7F2EA`
- 提亮纸色：`#FFFDF9`
- 墨色：`#302D29`
- 次级墨色：`#777067`
- 朱砂：`#AD3B29`
- 分隔线：`#DED6CA`
- 中文标题：宋体系统字体栈
- 正文与控件：苹方 / 系统无衬线字体栈

## 设计关键词

字体、沉浸式、精美视觉、分享卡片、情绪价值、个性化装饰、仪式感。

网页以编辑式排版、长留白、细分隔线和朱砂点题为核心。避免把每项能力包进通用圆角卡片；按钮只用于真实操作，状态使用非交互文本表达。动画仅用于轻微状态反馈，并遵守 `prefers-reduced-motion`。

## 命名规则

- 中文正式名：句刻 - 每日名言
- 中文短名：句刻
- 英文正式名：Daily Quote: 句刻
- 品牌署名：MicroSpotlight

中文页面首次出现使用正式名，后续使用“句刻”；英文页面使用 “Daily Quote: 句刻”，后续可缩写为 “Daily Quote”。
