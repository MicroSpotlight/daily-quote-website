隐私政策

生效日期：2026 年 8 月 18 日

Daily Quote 以数据最小化为原则。App 不要求注册账号，不出售或共享个人数据，也不用于跨 App 或网站追踪。需要联网的 Plus 能力都默认关闭或逐次征得同意。

1. App 中的数据

感兴趣的主题、收藏、个人手记、私人印记、语言与阅读偏好、提醒时间、阅读历史和 AI 解读默认保存在你的设备本地。我们无法访问这些内容。删除 App 通常会一并删除这些本地数据。

2. 内容更新服务

App 会向由 Cloudflare 承载的公开内容服务请求语录版本、增量更新或完整内容快照。请求不包含你的兴趣、收藏、手记、阅读历史、提醒设置、设备标识符或账号信息。与一般互联网连接相同，Cloudflare 可能为传输、安全和可靠性处理 IP 地址、请求时间、URL、网络路由与系统配置信息；我们只使用抽样的无正文技术日志排查服务错误，不据此建立用户画像。详情可参阅 Cloudflare 隐私政策。

3. Plus、AI 与内容反馈

当你购买或恢复句刻 Plus 时，App 会把 Apple 签名的交易凭证发送到 Cloudflare 承载的服务，用于核验订阅、试用、宽限期、退款、过期和家庭共享状态；我们不要求你创建 Daily Quote 账号。订阅状态核验记录只保留必要的交易标识、产品、状态和时间信息。

使用 AI 深度解读前，每次都需要你明确同意。默认只发送当前语录、语言和你主动输入的问题；如果你另外开启“本次附带本句手记”，并同时确认本次 AI 请求，才会额外发送当前手记（最多 2000 字）。请求会通过 Cloudflare AI Gateway 转发给 DeepSeek V4，用于生成本次结果。手记只作为本次不可信输入使用，不会被复述或用于推断敏感属性；Daily Quote 不把手记、问题或模型回复写入自己的数据库或日志，D1 只保留是否附带手记的审计标记，AI 解读仍只保存在本机，你可以随时导出或删除。

你主动提交内容纠错或出处反馈时，反馈正文、对应语录 ID 和提交时间会发送到内容服务，用于人工核对。离线时反馈会暂存在设备，联网后再提交；我们不会将它用于广告或用户画像。

4. 可选的 iCloud 私有同步

只有当你订阅 Plus 并主动开启 iCloud 私有同步时，收藏、偏好、阅读历史、手记、分享模板、专题进度和相关删除记录才会写入你 Apple 账号对应的 CloudKit 私有数据库。该数据由 Apple 按你的 iCloud 设置管理；AI 深度解读不会进入 iCloud。你可以在 App 设置中关闭同步并清除本机数据。

5. 通知

如果你开启每日提醒，Daily Quote 会请求系统通知权限，并在设备上安排本地通知。提醒设置与通知内容不会发送到我们的服务器。你可以随时在 App 或系统设置中关闭通知。

6. 分享

当你主动使用分享功能时，内容会交给 iOS 系统分享面板。你选择的第三方服务如何处理内容，由该服务的隐私政策约束；Daily Quote 不接收分享结果。

7. 分析、广告与追踪

Daily Quote 当前不包含广告 SDK、第三方分析 SDK、追踪技术或用户账户系统，也不收集设备标识符、位置、联系人、照片、搜索历史或使用行为。

8. 支持请求

如果你通过 GitHub Issues 联系支持，你主动提交的内容将由 GitHub 托管，并适用 GitHub 的隐私政策。请不要在公开问题中提交个人敏感信息。

9. 儿童隐私

Daily Quote 不面向儿童收集个人数据，也不会有意收集儿童的个人信息。

10. 政策更新

如果 App 的数据实践发生变化，我们会更新本页面和生效日期，并在需要时同步更新 App Store 的隐私信息。

11. 联系我们

如对本政策或 Daily Quote 有疑问，请前往 支持页面提交问题。
