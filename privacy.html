隐私政策

生效日期：2026 年 8 月 9 日

Daily Quote 以数据最小化为原则。App 不要求注册账号，不收集、上传、出售或共享个人数据，也不用于跨 App 或网站追踪。

1. App 中的数据

收藏的句子、主题与字号偏好、提醒时间等信息只保存在你的设备本地。我们无法访问这些内容。删除 App 通常会一并删除这些本地数据。

2. 通知

如果你开启每日提醒，Daily Quote 会请求系统通知权限，并在设备上安排本地通知。提醒设置与通知内容不会发送到我们的服务器。你可以随时在 App 或系统设置中关闭通知。

3. 分享

当你主动使用分享功能时，内容会交给 iOS 系统分享面板。你选择的第三方服务如何处理内容，由该服务的隐私政策约束；Daily Quote 不接收分享结果。

4. 分析、广告与追踪

Daily Quote 当前不包含广告 SDK、第三方分析 SDK、追踪技术或用户账户系统，也不收集设备标识符、位置、联系人、照片、搜索历史或使用行为。

5. 支持请求

如果你通过 GitHub Issues 联系支持，你主动提交的内容将由 GitHub 托管，并适用 GitHub 的隐私政策。请不要在公开问题中提交个人敏感信息。

6. 儿童隐私

Daily Quote 不面向儿童收集个人数据，也不会有意收集儿童的个人信息。

7. 政策更新

如果 App 的数据实践发生变化，我们会更新本页面和生效日期，并在需要时同步更新 App Store 的隐私信息。

8. 联系我们

如对本政策或 Daily Quote 有疑问，请前往 支持页面提交问题。
